# Локальная синхронизация Obsidian

Проект настройки локальной двусторонней синхронизации хранилища Obsidian между ноутбуком Windows и телефоном Android с помощью Syncthing. Цель — передавать заметки напрямую в локальной сети, без подписки и облачного хранилища.

## Текущее хранилище

Папка Obsidian: `<ПУТЬ_К_ХРАНИЛИЩУ_OBSIDIAN>`.

## Состояние

- Syncthing установлен на Windows; автоматические обновления и ретрансляторы при установке отключены.
- В настройках Windows оставлено локальное обнаружение; глобальное обнаружение, NAT traversal и ретрансляторы отключены.
- Папка `ObsidianVault` добавлена и расшарена с Android-устройством.
- Syncthing-Fork установлен на Android; оба устройства добавлены друг к другу.
- На последнем снимке ноутбук ещё не подключился к телефону: Syncthing показывал 4 206 несинхронизированных объектов (примерно 74,8 МиБ). Следующий этап — исправить локальное сетевое подключение при включённом VPN и завершить первоначальную передачу.

## Принципы безопасности

Не добавлять в Git содержимое хранилища, `config.xml`, сертификаты Syncthing, ключ API, полные Device ID, пароли или другие секреты. В репозитории хранить только документацию проекта и безопасные шаблоны.

## Этапы

1. Завершить прямое соединение устройств и первичную синхронизацию.
2. Улучшить удобство повседневной работы: автоматический запуск на Windows и Android, синхронизация по Wi-Fi, понятный путь хранилища и проверка конфликтов.
3. Проверить передачу изменений в обе стороны и зафиксировать результат.
