# Ошибка создания папки в Syncthing-Fork для Android

## Как повторить

1. Открыть создание новой папки.
2. Нажать кнопку создания/сохранения до заполнения обязательных полей.
3. Приложение показывает сообщение, что не задано имя папки.
4. Заполнить имя и остальные обязательные поля.
5. Кнопка создания/сохранения остаётся отключённой.

## Причина в исходном коде

В `FolderActivity.onOptionsItemSelected()` пункт сохранения отключается до вызова `onSave()`. Если проверка обязательных полей не проходит, `onSave()` показывает сообщение и сразу возвращается. Ветка ошибки не включает пункт меню обратно.

## Исправление

Не отключать пункт до проверки полей. `onSave()` уже вызывает `setSavingState(true)` только после успешной проверки; этот вызов штатно отключает кнопку на время сохранения.

Подготовлен минимальный патч: [syncthing-fork-enable-create-after-validation.patch](patches/syncthing-fork-enable-create-after-validation.patch). Он предназначен для Android-репозитория [researchxxl/syncthing-android](https://github.com/researchxxl/syncthing-android), а не для Windows-ветки проекта. Патч ещё не собран и не установлен на телефон.

## Временный обход

В текущей установленной версии заполнить обязательные поля до первого нажатия кнопки создания.
