# Кнопка синхронизации Obsidian для Windows

Дважды щёлкните `Запустить_синхронизацию.cmd`. Откроется небольшое окно с кнопкой **Синхронизировать сейчас**. Программа обращается только к Syncthing на этом компьютере, запускает его при необходимости и просит заново проверить выбранную папку. Дальше Syncthing сам передаёт изменения подключённым устройствам.

Ключ API берётся из локального `config.xml` Syncthing и не показывается, не записывается в журнал и не отправляется в Интернет. Если в Syncthing несколько папок, выберите `dlia_mislei` или папку хранилища Obsidian.

Требования: Windows PowerShell 5.1 и установленный Syncthing с уже настроенной папкой хранилища. Если приложение ещё не запускали и файл настроек не создан, откройте Syncthing один раз, затем запустите кнопку повторно.

Это пока небольшой Windows-помощник, а не отдельный установщик. Он инициирует сканирование папки; он не может синхронизировать телефон, пока Syncthing не запущен на телефоне и устройства имеют сетевое соединение.
