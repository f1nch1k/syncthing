# Локальная синхронизация Obsidian

Проект настройки двусторонней синхронизации Obsidian между ноутбуком Windows и Android через Syncthing, без облачной подписки. Рабочая ветка создана от `main` форка [f1nch1k/syncthing](https://github.com/f1nch1k/syncthing/tree/obsidian-local-sync-project); исходная `main` не изменена.

## Цель

Упростить ежедневный обмен заметками, сохраняя файлы в локальной сети и оставляя Planet VPN включённым для остальных приложений.

## Состояние

Syncthing установлен на Windows, папка хранилища `dlia_mislei` добавлена и расшарена с Android. Syncthing-Fork установлен на телефоне; устройства добавлены, но по последним снимкам соединение не установлено. Следующий шаг — получить IPv4 Wi-Fi ноутбука и выполнить прямой тест, не используя адреса VPN или виртуальных адаптеров.

- [Помощник для определения IPv4-адреса LAN](tools/Get-SyncthingLanAddress.ps1)

Помощник Windows показывает IPv4-адреса частной локальной сети и готовую строку для поля адреса устройства Syncthing. Он исключает типичные VPN- и виртуальные адаптеры и не меняет сетевые настройки. При нескольких LAN-адаптерах нужно выбрать тот же Wi-Fi, к которому подключён телефон.

## Ограничения публикации

Не добавлять содержимое хранилища, полный путь к личным файлам, конфигурации Syncthing, полные Device ID, ключи API или пароли. В репозитории хранится только описание настройки.
