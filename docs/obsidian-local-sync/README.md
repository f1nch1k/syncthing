# Локальная синхронизация Obsidian

Проект настройки двусторонней синхронизации Obsidian между ноутбуком Windows и Android через Syncthing, без облачной подписки. Рабочая ветка создана от `main` форка [f1nch1k/syncthing](https://github.com/f1nch1k/syncthing/tree/obsidian-local-sync-project); исходная `main` не изменена.

## Цель

Упростить ежедневный обмен заметками, сохраняя файлы в локальной сети и оставляя Planet VPN включённым для остальных приложений.

## Состояние

По последнему сообщению пользователя, подключены три устройства; на снимке Windows папки показывали состояние «В актуальном состоянии». Двусторонний проход тестовой заметки всё ещё не подтверждён. При последней проверке запуск через `stctl.exe` завершился ошибкой Windows о перемещении системной DLL, поэтому приложение не осталось запущенным.

Помощник Windows отдельно показывает адрес точки доступа ноутбука (Wi-Fi Direct) и обычной локальной сети, а также готовую строку для Syncthing. Когда телефон подключён к точке ноутбука, нужно выбрать строку **Windows hotspot**. Скрипт только читает сведения сетевых адаптеров и не меняет VPN или другие настройки.

Добавлен первый вариант отдельной кнопки Windows: она просит Syncthing перепроверить выбранную папку Obsidian, после чего Syncthing передаёт изменения подключённым устройствам. Его нужно запустить и проверить на ноутбуке; передачу заметки в обе стороны также нужно подтвердить отдельно.

## Ограничения публикации

Не добавлять содержимое хранилища, полный путь к личным файлам, конфигурации Syncthing, полные Device ID, ключи API или пароли. В репозитории хранится только описание настройки.
